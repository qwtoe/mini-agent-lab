# Repository instructions

- Write commit messages using the Angular commit message format: `<type>(<scope>): <summary>`. The scope is optional.
- Use an imperative, present-tense, lowercase summary without a trailing period.
- Common types include `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, and `ci`.
- Separate an optional body or footer from the header with a blank line. Describe breaking changes in a `BREAKING CHANGE:` footer.
- Keep repository content in English.
